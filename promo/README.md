# Promo media

Raw in-game material for future promotion (mod pages, website, trailers).

- `screenshots/` - in-game images (PNG preferred)
- `videos/` - short clips (MP4 preferred, keep each file under 100 MB so GitHub accepts it)

Name files with a short description and the date, for example `panel-queue-2026-11-14.png`.

Images already used on the mod pages live in `docs/screenshots/`.
